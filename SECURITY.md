# Security reporting

Report vulnerabilities privately through the GitHub reporting link below. Include host, Library and Updater versions, environment, reproduction, and impact; omit credentials and personal content. Ordinary bugs belong in Issues. If private GitHub reporting is unavailable, do not post security details publicly.
